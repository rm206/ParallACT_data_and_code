Another agent is working in this same repository at the same time on a related requirement. You can exchange messages with them: run `./send-msg "your message"` to send, and `./recv-msg` to read any new messages from the other agent. Treat the work as a sequence of sync points: before starting implementation, send your plan and the interfaces you intend to define, then run `./recv-msg` to read theirs; after each significant change, send it and run `./recv-msg` to reconcile; before finishing, confirm your assumptions against theirs. Do not finalize an interface decision without running `./recv-msg` first.
